# Description

This repo contains my solutions for various leetcode.com programming problems

# Requirements

- cmake
- gcc
- git

## How To Build
```
git clone https://github.com/ryanbonus/leetCodeSolutions.git
```
OR (For SSH)
```
git clone git@github.com:ryanbonus/leetCodeSolutions.git
```

```
cd leetCodeSolutions/cpp
cmake -S . -B build
cmake --build build
```
## Running Tests
```
cd build
ctest
```
